# OCR (Optical Character Recognition) 

This repository contains an OCR project that extracts text from images and converts it into machine-readable text.

## Features
- Extract text from images
- Recognize printed text
- Convert images into editable text

## Technologies Used
- Python
- OpenCV
- Tesseract OCR
- EasyOCR

## Goal
To learn and implement Optical Character Recognition using Python and image processing techniques.
